<h1 align="center">Лабораторная работа №3</h1>

<h2> Цель лабораторной работы: </h2>
<h5> Реализовать простой генетический алгоритм для нахождения аппроксимации представленной функции.</h5>
<h6>Язык: Python</h6>
<h6>  
Входные данные:
 
Множество точек на поверхности (500-100);

Размер популяции P (1000-2000);

Em, Dm - среднее значение и дисперсия для мутации для генерации случайного числа мутировавших генов;

maxIter - максимальное количество поколений;

maxConstIter - максимальное количество поколений с ​​постоянным значением наилучшей приспособленности (fitness).

	
Выходные данные: 

Время вычисления на GPU;

Набор коэффициентов полинома, аппроксимирующего заданный набор точек;

Лучшее значение приспособленности;

Номер последнего поколения.
</h6>

<h2> Описание проделанной работы: </h2>
<h5> 
В результатет выполнения данной работы был реализован простой генетический алгоритм. 
Вычисления производились на GPU с применением CUDA.
</h5>

<h2> Что было распараллелено: </h2>
<h5> Каждый поток обрабатывает отдельный индивидуум из популяции, вычисляя для каждого из них собственное значение приспособленности.</h5>

<h2> Как производились вычисления: </h2>
<h5> 
 
1. Генерация начальной популяции случайных полиномов.

2. Для каждого индивидуума в популяции вычисляется фитнес, который оценивает, насколько хорошо полином приближает целевую функцию.

3. С помощью функции time() определяется время, затраченное на вычисление фитнеса на CPU.

4. Данные о популяции и точках передаются на GPU для параллельного вычисления фитнеса с использованием функции fitness.

5. На GPU каждый поток вычисляет фитнес для отдельного индивидуума, суммируя ошибки по всем точкам.

6. После завершения вычислений фитнес-значения копируются обратно на CPU.

7. С помощью функции time() определяется время, затраченное на вычисление фитнеса на GPU с использованием CUDA.

8. Выполняется селекция, скрещивание и мутация для создания нового поколения.

9. Процесс повторяется на заданное количество поколений или до достижения критерия остановки.

</h5>
