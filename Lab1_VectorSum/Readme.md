<h1 align="center">Лабораторная работа №2</h1>

<h2> Цель лабораторной работы: </h2>
<h5> Реализовать алгоритм сложения элементов вектора.
 Реализация должна содержать 2 сложения элементов вектора: на CPU и на GPU с применением CUDA.</h5>
<h6>Язык: Python</h6>
<h6>  
	Входные данные: Вектор размером 1 000..1 000 000 значений.
	
Выходные данные: сумма элементов вектора + время вычисления</h6>

<h2> Описание проделанной работы: </h2>
<h5> 
В результате выполнения данной работы было реализовано 2 алгоритма сложения элементов вектора. 
Сложение элементов вектора на CPU стандартными средствами Python, а также на GPU с применением CUDA.
</h5>

<h2> Что было распараллелено: </h2>
<h5> Каждый поток рассчитывает сумму группы элементов вектора с определенным шагом, который задается размерностью блока.</h5>

<h2> Как производились вычисления: </h2>
<h5> 

 
1. Генерация вектора.
	
2. Производится последовательное суммирование элементов вектора на CPU.
   
3. С помощью функции time() определяется время затраченное на перемножение матриц на CPU.
   
4. Вектор разбивается на блоки для параллельного суммирования элементов на GPU.

5. После расчёта суммы блоков производится сложение частичных сумм на GPU.
   
6. С помощью функции time() определяется время затраченное на перемножение матриц на GPU с CUDA.


</h5>


<h2> Оборудование: </h2>
<h5>  
	
CPU: AMD Ryzen 7 PRO 2700 Eight-Core Processor  
	
GPU: NVIDIA GeForce GTX 1060 6GB  
</h5>
